# 大飞AIPPT（dafei-ai-ppt）

一句话做出真正能用的网页 PPT：5 种风格 + 大飞5步法（明确用途 → 查缺补漏 → 追问理清思路 → 观点句大纲 → 生成并防编造检查）。

赶时间？把文档丢给它，说一句“直接做”，就会跳过前 4 步直接生成；数字不编造的检查始终保留。

| 风格 | 模板 | 适合 |
|---|---|---|
| A 电子杂志风 | assets/template.html | 分享、行业观察 |
| B 瑞士国际主义风 | assets/template-swiss.html | 数据、科技、设计 |
| C 商务汇报风（新增） | assets/template-business.html | 工作汇报、方案 |
| D 科技发布会风（新增） | assets/template-tech.html | AI 产品发布、Demo Day |
| E 国潮东方风（新增） | assets/template-guochao.html | 文化、品牌、培训 |

预览：assets/previews/

源码地址：https://github.com/MatteoVoss/dafei-ai-ppt

## 使用
在 WorkBuddy 的「技能」里添加本技能（或在技能市场搜索"大飞AIPPT"），对话中输入"/"选择大飞AIPPT，说清主题、用途和风格即可。
